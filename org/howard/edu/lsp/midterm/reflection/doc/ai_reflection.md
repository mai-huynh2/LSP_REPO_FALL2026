If you asked me a couple of years ago, I would’ve told you that I was very skeptical of AI. I was worried that relying on it would make it harder to learn independently and think through problems myself. Throughout the past few years and more specifically, this course, I started to see how it could be useful when I took the time to understand its suggestions. For example, in Assignment 3, we refactored the ETL pipeline into separate classes. Using AI helped me understand why reading a CSV file and representing an employee should be handled by different classes. Seeing those ideas applied to an assignment made concepts like encapsulation and separating responsibilities easier to understand and work through. I also started to see how AI could handle tedious tasks more efficiently than I could, giving me more time and mental space to focus on creative or innovative solutions to problems which is what I believe is the best way to use it for. I hold the belief that AI is a tool and a tool only.

A limitation that I noticed is that getting working code doesn’t necessarily mean I understand it. When I used AI for help with assignments, sometimes I still had questions about where files belonged or how the different parts fit together. This showed me how easy it is to follow instructions without fully understanding the process. So to address this and make sure that I was really comprehending the “why”, I asked follow-up questions and compiled and ran the code myself. For example, I compiled these Java files for the midterm in PowerShell to check for syntax errors. However, I still needed to review the logic and assignment requirements because code can compile successfully without doing everything it’s supposed to do.

In the future, I plan to use AI for explanations, debugging suggestions, and help with repetitive tasks, while continuing to practice writing code independently. Before asking for a solution, I want to attempt the problem myself and figure out where I’m  stuck. When AI suggests a change, I want to be able to explain why it works before using it. My view of AI has definitely become more open, but I still think its value depends on how I (and everyone else) uses it. Time is something we can never get back so saving it where I can is helpful, especially if I can use that time to think more creative and proactive things.
